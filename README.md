# বাজার দর

চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম-দুধ আর মসলার আজকের দাম এক জায়গায় দেখার ওয়েব অ্যাপ। কোন জিনিসের দাম বাড়ছে, কমছে, আর কোন বাজারে কত — সব এক নজরে।

## 🛠️ যা যা ব্যবহার করেছি

- **Next.js** (App Router) — ফ্রেমওয়ার্ক আর রাউটিং
- **TypeScript** — টাইপ সেফটির জন্য
- **Tailwind CSS** — স্টাইলিং
- **Better Auth** — লগইন, সাইনআপ, সেশন
- **MongoDB Atlas** — ইউজার ডেটা রাখার জন্য
- **React Hot Toast** — নোটিফিকেশন
- **Lucide React** — আইকন
- **Hind Siliguri** — বাংলা ফন্ট

## ✨ ফিচার

- ৮টা ক্যাটাগরির পণ্যের আজকের দাম — চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম-দুধ, মসলা
- নেভবারের নিচে চলমান প্রাইস টিকার, যেখানে দাম বাড়া-কমা দেখা যায়
- "আজ দাম বেড়েছে" আর "আজ দাম কমেছে" — দুটো আলাদা সেকশনে টপ ৬টা পণ্য
- ক্যাটাগরি পেজে দাম দিয়ে সর্ট করা যায় (কম থেকে বেশি / বেশি থেকে কম)
- প্রোডাক্ট ডিটেইল পেজে বাজারভিত্তিক সর্বনিম্ন, সর্বোচ্চ আর গড় দাম — লগইন করা ইউজারদের জন্য
- ইমেইল/পাসওয়ার্ড দিয়ে সাইনআপ-সাইনইন, সাথে Google আর GitHub লগইন
- প্রোফাইল পেজ থেকে নাম আপডেট করা যায়
- মোবাইল, ট্যাবলেট, ডেস্কটপ — সব জায়গায় কাজ করে
- কাস্টম 404 পেজ, লোডিং স্কেলিটন আর টোস্ট মেসেজ
